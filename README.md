# networkcurrency.com

The website of Network Currency LLC, built with Astro and served by GitHub Pages.

[`CLAUDE.md`](CLAUDE.md) and [`CONVENTIONS.md`](CONVENTIONS.md) are the rules for working in this repository.

## Run it locally

```bash
npm install
npm run dev
```

The site opens at http://localhost:4321. `npm run check` validates types and content, and `npm run build` writes the site to `dist/`.

## Content

All site copy lives in `src/content/`. Layouts and components hold structure only.
